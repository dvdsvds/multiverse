## Divergence (발산 / 분기)
말 그대로 "갈라짐"이에요. 똑같은 출발점에서 시작한 두 개가 시간이 지나면서 점점 달라지는 현상. 이 프로젝트에선 같은 `base`성격을 가진 '나'가 우주마다 다른 환경을 겪으면서 서로 다른 성격으로 벌어지는 걸 말해요. 반대말은 수렴(converge, 점점 같아짐)이에요. 문서 제목의 State Divergence가 이거예요. - 상태가 갈라지는 것

### [Divergence QnA](./qna/divergence_qna.md)

## Agent (에이전트) / State (상태)
- Agent : 시뮬레이션 속의 '개체', 즉 우주 하나에 사는 '나'한 명이에요.
- State : 그 개체가 지금 어떤 상태인지를 숫자로 표현한 것. 성격 값들, 나이, 살아있는지 여부 같은 거요. 시간이 지나면 이 State가 계속 바뀌어요.

### [Agent, State QnA](./qna/agent_state_qna.md)

## Universe (우주) / Tick (틱)
- Universe : 서로 독립된 하나의 세계. 각 우주는 생존 난이도, 사고 확률 같은 환경이 조금씩 달라요.
- Tick : 시뮬레이션의 시간 한 칸. 게임의 한 프레임이라고 보면 돼요. 매 tick마다 에이전트한테 무슨 일이 일어나고 성격이 조금씩 갱신돼요.

### Thinking
1. 객체가 살아가는 곳이 지구가 아닐 수 있다는 것도 가정을 해야하나?
2. tick마다 성격이 조금씩 갱신된다는데, 외부 요인들도 변수로 만들어둬야 하는 것이 아닌가?

## Montte Carlo (몬테카를로)
"무작위로 엄청 많이 돌려보고 통계를 낸다"는 방법이에요. 우주 하나만 보면 우연이라 판단이 안 되지만, 1,000개를 돌려서 "70%가 살아남았다"처럼 비율을 보면 경향이 보여요. 이 프로젝트 전체가 이 방식이에요.

## Seed (시드)  / PRNG
컴퓨터의 무작위는 사실 "시드"라는 시작 숫자로 만들어지는 가짜 무작위예요(PRNG = 유사난수 생성기). 같은 시드를 넣으면 **항상 같은결과**가 나와요. 그래서 우주마다 다른 시드를 주면 다른 세계가 되고, 나중에 같은 시드로 그 우주를 똑같이 재현 할 수 있어요.

### Thinking
1. 지금 현재 이 프로젝트는 무한 다중 우주를 생각하고 있는데 컴퓨터의 숫자로 무한을 표현이 가능한가? -> 불가능하다고 생각하는데 어떻게 무한 다중 우주를 구현을 하나?
2. 같은 시드로 우주를 똑같이 재현이 가능하다고 하는데 같은 환경, 똑같은 시간대여도 그 우주를 많이 복사해서 두었을 때 객체가 과거에 했던 행동과 다른 행동을 할 확률이 낮지 않다고 봄 -> 이거는 너무 간 생각인가?

## Cosine Similarity (코사인 유사도) / Distance (거리)
두 성격 벡터가 얼마나 비슷한지 숫자로 재는 방법들이에요. base인 '나'와 우주 속 '나'가  얼마나 벌어졌는지 (=divergence 정도)를 이걸로 측정해요. 지금은 "비슷함을 숫자로 잰다" 정도만 알면 충분해요.

### Thinking
1. 코사인 유사도, 성격 벡터가 아직 뭔지 모름.
2. 얼마나 벌어졌는지가 기준이 되는 base인 '나'와 수치가 얼마나 달라져서 갈라졌는지(발산, divergence)가 Distance 인가?

## Clustering (클러스터링)
비슷한 것끼리 자동으로 묶는 것. 1,000개의 갈라진 '나'들을 성격 유형별로 그룹핑하면 "아 크게 3가지 방향으로 갈라졌구나"가 보여요. 문서의 "Divergence Spectrum"이 이 결과예요.
