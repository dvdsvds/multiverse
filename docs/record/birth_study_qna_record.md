# 탄생 판정(NOT_BORN) 학습 Q&A 기록

내가 실제로 던진 질문/생각(원문 그대로) + 답변과 유도 과정.
주제: 우주에서 '나'가 태어나느냐 마느냐(NOT_BORN)를 어떻게 판정하는가.

---

## 배경: base는 같은 나라·같은 인종으로 고정

### 🧠 내 결정 (원문)
> 너무 복잡하니까 base는 같은 나라 사람, 같은 인종으로하자

### ✅ 정리 — 실험을 깨끗하게
- base를 고정하면 갈라짐의 원인이 **환경(시드)으로만** 깔끔하게 귀속됨.
- 변수를 하나(시드)만 풀어 원인을 분리한다는 원칙 그대로.
- 국적/종(種) 차이는 base 자체가 달라지는 문제 → **별도 실험으로 미룸**(판타지 지구와 같은 취급).
  - 국적 차이 중 "환경 차이"(어떤 이벤트가 자주 터지나)는 나중에 넣을 수 있으나, base를 바꾸는 부분은 제외.

---

## Q1. 태어나느냐 마느냐를 뭘로 판정하나?

### 🧠 내 답 (원문)
> 확률이지 / 확률이랑 가중치 (둘 중 뭔지 고민)

### ✅ 정리 — 확률 하나 (가중치 아님)
핵심 차이: **선택지가 몇 개냐.**
- **가중치**: 여러 개 중 **하나를 고를 때** (교통사고/승진/로또... 이벤트 종류 뽑기).
- **확률 하나**: 결과가 **둘 중 하나(예/아니오)일 때.** 동전처럼.

"태어난다 / 안 태어난다" = 딱 둘 → **확률 하나면 됨.**
```
p_born = 0.9   (이 우주에서 태어날 확률)
r = random(0, 1)
if r < p_born: 태어남 (ALIVE로 시작)
else:          NOT_BORN
```
- 여러 개 중 선택 → 가중치 / 예·아니오 → 확률 하나 (사고 발생 여부도 이쪽).

## Q2. p_born은 모든 우주가 같아야 하나, 달라야 하나?

### 🧠 내 생각 (원문, 처음엔 이유가 어긋남)
> 우주마다 달라야 한다 / 관전자도 예측 못하게 해야지
> 0.9로 고정하면 몇 %에서 태어나는지 예측되니까 목표랑 안 맞음 / 몬테카를로도 적용 안 될 거 같음

### ✅ 정리 — 결론은 맞고(우주마다 다름), 이유는 교정
내 주장이 반은 맞고 반은 틀렸음:

**틀린 반쪽 — "비율이 예측되면 목표랑 안 맞는다"**
- p_born을 0.9로 고정해도 **개체 예측은 여전히 불가**(어느 우주에서 안 태어날지는 난수라 모름). 내가 원한 "예측 불가"는 여기서 이미 살아있음.
- "1,000개 중 약 90% 태어남"으로 **비율이 수렴**하는 것 = 실험이 고장난 게 아니라 **결과 그 자체**. 그게 몬테카를로의 목적.
- 앞서 정리한 **"개체는 흩어지고, 비율은 수렴한다"** 그대로.
- → "몬테카를로가 적용 안 된다"는 반대. 고정이든 변동이든 몬테카를로는 그대로 작동.

**맞는 반쪽 — p_born을 우주마다 다르게 하는 진짜 이유**
- ❌ 예측을 막으려고 → 아님(확률이 이미 개체 예측을 막고, 비율 예측은 목적).
- ⭕ **우주마다 환경(탄생 난이도)이 다르니까.** 어떤 우주는 태어나기 쉽고 어떤 우주는 어려움. 그래야 우주가 진짜 "제각각인 세계"가 됨.
- p_born을 우주마다 다르게 해도 전체 평균은 또 수렴 → 몬테카를로 문제없음.

## Q3. 우주마다 다른 p_born을 어디서 가져오나?

### 🧠 내 답 (원문)
> 시드?

### ✅ 정리 — 시드에서 파생
```
우주 생성 → 시드 주어짐
          → 시드로 이 우주의 p_born 결정 (예: 0.5~0.99 중)
          → 난수 굴려 태어남/NOT_BORN 판정
```
- **우주마다 다름**: 시드가 다르니 p_born도 제각각. (환경마다 다른 탄생 난이도)
- **재현 가능**: 같은 시드 → 같은 p_born.
- "우주의 모든 환경 변수는 시드에서 파생"이라는 구조 그대로. p_born은 그 환경 변수 중 하나(생존 난이도·사고 확률·이벤트 분포 옆에 추가).

---

## 🔑 NOT_BORN 판정 최종
```
1. 시드에서 이 우주의 p_born 파생
2. r = random(0, 1)
3. r < p_born → 태어남 (ALIVE 시작, tick 루프 진입)
   else       → NOT_BORN (이 우주는 여기서 끝, 최종 상태 = 안 태어남)
```

**집계 주의**: NOT_BORN도 **탐색한 우주 수(분모)에 포함**해야 함. "안 태어난 우주"도 하나의 결과. 빼먹으면 생존율이 편향됨(metrics 때 짚은 것과 동일).

### 우주 하나의 완전한 생애 (이제 완성됨)
```
시드 → p_born 판정 ┬ (태어나면) tick 루프 [이벤트 → f → status] → 죽음/T_end → 최종 상태
                   └ (안 태어나면) NOT_BORN
```
