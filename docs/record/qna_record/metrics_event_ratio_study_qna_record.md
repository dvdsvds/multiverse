## Q1. R_exist (생존율) 계산

### 🧠 내 식 (원문)
> ALIVE / (TERMINATED + NOT_BORN)

### ✅ 정리 — 분모에 ALIVE가 빠졌음
검증:
```
ALIVE 700, TERMINATED 200, NOT_BORN 100
내 식: 700 / (200+100) = 2.33 → 233%   ← 100% 넘음, 이상
```
- 문제: 생존율 = "**전체 중** 산 비율"이라 분모가 **전체**여야 함. 살아남은 700도 전체의 일부라 분모에 포함.
```
R_exist = ALIVE / (ALIVE + TERMINATED + NOT_BORN)
        = 700 / 1000 = 0.7 → 70%  ✓
```
- metrics에서 "분모는 전체, NOT_BORN도 포함"이라던 그 얘기. NOT_BORN은 넣었는데 ALIVE를 빼먹은 것.

### 세 결과를 각각 비율로
```
탄생 실패율 = NOT_BORN   / 전체
사망률     = TERMINATED / 전체
생존율     = ALIVE      / 전체
→ 셋 합 = 100%
```
- **핵심: 비율의 분모는 항상 "전체". "산 것 / 죽은 것"이 아니라 "산 것 / 전체".**

## Q2. S_identity (base 대비 유사도)

거리 ↔ 유사도는 **방향이 반대**:
- 거리: 멀수록 큼 / 유사도: 비슷할수록 큼. 거리 크면 유사도 작아야 함.

### 🧠 내 생각 (원문)
> 반비례 아닌가? 거리/유사도?

### ✅ 정리 — 반비례(나누기)는 방향은 맞지만 곤란
"유사도 = 1 / 거리"로 보면:
```
거리 0.5 → 2 / 거리 0.1 → 10 / 거리 0 → 1/0 = 터짐!
```
- 문제 1: **거리 0(완전 동일)에서 0으로 나누기 → 터짐.**
- 문제 2: 값 범위가 제멋대로(2, 10...) → % 로 읽기 어려움.

### ✅ 더 나은 방법 — 빼기
```
S_identity = 1 - 거리        (거리 0~1일 때)
  거리 0   → 1 - 0   = 1   (100%, 완전 동일) ✓
  거리 0.3 → 0.7          (70% 닮음)
  거리 1   → 0           (0%, 완전 다름) ✓
```
- 방향도 맞고, 안 터지고, 범위 0~1로 깔끔 → ×100 하면 "몇 % 닮음".
- **"반대로 만들기"에는 나누기 말고 빼기도 있다. 여기선 빼기가 훨씬 나음.**
- 조건: `1 - 거리`가 깔끔하려면 거리가 0~1이어야 함. 유클리드 거리는 축이 많으면 1 초과 가능(√5≈2.2) → 거리를 먼저 **정규화**한 뒤 `1 - 거리`. (세부 구현, 지금은 개념만)

### 확정
```
R_exist    = ALIVE / 전체
S_identity = 1 - (정규화된 base 거리)
```

## Q3. 이벤트 좋은/나쁜 비율을 우주 파라미터와 연결

배경: 이벤트 뽑기 1단계 "좋은 일/나쁜 일" 비율 = 우주 성향(평탄/험난). 이걸 어디서 가져오나.

### 🧠 내 답 (원문)
> 시드에서 파생??

### ✅ 정리 — p_born과 같은 구조
```
우주 생성 → 시드
 → 시드로 p_born 파생
 → 시드로 나쁜 일 비율 파생 (예: 0.3~0.7)
 → 시드로 생존 난이도·사고 확률·이벤트 분포 파생
```
- 시드에서 파생 → 우주마다 다름 + 재현 가능. "나쁜 일 비율"은 환경 파라미터에 하나 추가.

## Q4. 파라미터들을 독립으로 둬도 되나? (예: 나쁜 일 많은데 안 죽는 우주)

### 🧠 내 반박 (원문)
> 왜 이상하게 느껴져? 나쁜 일이 터지는데 그 객체의 운이 좋아서 안 죽을 수도 있고, 안 죽는 이유가 있겠지?

### ✅ 정리 — 독립이 맞음
- "나쁜 일 많은데 안 죽는 우주" = **운 좋은 우주 / 회복력 강한 우주**. 이상한 게 아니라 오히려 다양성.
- 억지로 묶으면(나쁜 일↑ → 무조건 많이 죽음) 내가 각본을 쓰는 셈 → "예상 못 한 우주"가 안 나옴.
- **파라미터는 각자 독립적으로 시드에서 파생. 억지 상관관계 안 넣음.**
- (성격 축 상관관계를 2차로 미룬 것과 같은 결 — 억지로 안 엮고 독립·단순하게. 필요하면 나중에.)

### 확정
```
우주 환경 파라미터 (전부 시드에서 독립 파생):
- p_born (탄생 확률)
- 나쁜 일 비율 (이벤트 1단계 좋은/나쁜)  ← 이번 추가
- 생존 난이도
- 사고 확률
- 이벤트 분포
→ 서로 독립. 다양한 조합 허용.
```

## 🔑 최종 정리
- **R_exist** = ALIVE / 전체 (분모는 항상 전체)
- **S_identity** = 1 - (정규화 거리) (빼기가 나눗셈보다 깔끔)
- **이벤트 나쁜 일 비율** = 시드에서 독립 파생, 다른 파라미터와 억지로 안 엮음
