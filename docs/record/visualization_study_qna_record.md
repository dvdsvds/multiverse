# 시각화(Visualization) 학습 Q&A 기록

내가 실제로 던진 질문/생각(원문 그대로) + 답변과 결정 과정.
주제: 지금까지의 결과를 어떻게 눈으로 보여줄까 (분기 스펙트럼).

> 이 파트는 새 개념 학습이라기보단, 만든 결과를 어떻게 표현할지 "결정"하는 단계. 내가 뭘 보고 싶은지가 핵심.

---

## 손에 있는 것
- 각 우주의 최종 성격 벡터 (PCA로 2D/3D로 누른 것)
- 각 점이 어느 클러스터(유형)인지
- base에서 얼마나 멀어졌는지(유클리드 거리)
- 생존 여부 (ALIVE / TERMINATED / NOT_BORN)

---

## Q1. 어떤 그림을 볼까 — A / B / C

후보:
- **A. 흩어진 점 + 색깔로 유형 구분**: PCA 2D 평면에 점을 뿌리고 클러스터별 색. "몇 덩어리로 갈라졌나"가 한눈에. (분기 스펙트럼)
- **B. 분기 트리**: base 하나에서 갈라져 나가는 나무 모양.
- **C. 분포/히스토그램**: base 거리별 우주 개수.

### 🧠 내 선택 (원문)
> base에서 거리가 얼마인 우주가 몇 개인건 관심이 없어. A나 B가 제일 좋은데
> B는 아니다 A가 맞다. (B의 두 갈래) 둘다 아니야

### ✅ 정리 — A로 확정
- **C 탈락**: 거리 분포엔 관심 없음.
- **B 탈락**: 분기 트리는 두 방향이 있는데 둘 다 내가 원하는 게 아님:
  - "퍼져나가는 연출" → A 위에 base 중심 선으로 연출 가능하지만 원치 않음.
  - "유형 간 친척 관계(계층)" → 계층적 군집화 필요(k-means와 안 맞고 규모 문제). 원치 않음.
- → 계층 구조도, 퍼짐 연출도 아니고 **결과를 있는 그대로 보여주는 A.**

각 항목이 답하는 질문:
- **A**: 몇 유형? 각 유형 크기? 유형 간 거리?
- **B**: 갈라지는 과정? 유형 간 계층? ← 우리 관심 아님

## Q2. 죽은 우주는 어떻게?

산점도는 "살아남아 최종 성격이 나온 우주"만 점으로. 죽은/안 태어난 우주는 성격 벡터가 없거나 의미 없음.

### 🧠 내 결정 (원문)
> 죽은 우주들은 따로 개수만 해주고 시각화하는 곳에는 표현하지말자

### ✅ 정리
- **산점도**: 살아남은 우주만 점으로 (성격 유형 분포만 깨끗하게).
- **숫자로 따로**: NOT_BORN / TERMINATED / ALIVE 개수 (R_exist 등). metrics에서 정한 것.
- 산점도와 생사 통계를 섞지 않음 → 둘 다 명확.

---

## Q3. 2D냐 3D냐

- **2D**: 평면. 한눈에 파악, 화면에 딱. 5D→2D라 정보 손실 조금 더.
- **3D**: 입체. 축 하나 더 살림. 돌려봐야 하고 각도에 따라 겹침. (Plotly는 3D 회전 기본 지원)

### 🧠 내 결정 (원문)
> 한 눈에 볼 수 있게 하자

### ✅ 정리 — 2D로 확정
- 목적이 "한눈에"라 2D가 맞음. 돌려볼 필요 없고 클러스터 분포 즉시 파악.
- 원래 "결과를 눈으로 보고 싶다"는 목적과 일치.

## 🔑 시각화 최종
```
Plotly 2D 산점도 (= 분기 스펙트럼)
- 점 = 살아남은 우주 하나 (PCA로 5D→2D 누른 좌표)
- 색 = k-means 유형(클러스터)
- 죽은/안 태어난 우주는 점으로 안 그림
- 옆에 숫자로: ALIVE / TERMINATED / NOT_BORN 개수 (생존율 등)
```
→ "1,000명의 내가 몇 유형으로 갈라졌나"가 한 장으로.

## 나중 확장 아이디어 (지금은 접어둠)
- **시간 애니메이션**: tick이 흐르며 점들이 base 한 곳에서 점점 흩어지는 과정. (Plotly 지원)
- **개별 우주 파고들기**: 점 클릭 → 그 우주의 생애 로그(몇 살에 무슨 이벤트로 성격이 어떻게 변했나). "각자 어떻게 살았나"의 상세 버전.
- 1차 산점도가 잘 나온 뒤 붙이면 됨.
