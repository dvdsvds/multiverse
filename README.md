# Multiverse Agent Evolution & State Divergence Simulator

> 동일한 초기 상태(base)를 가진 '나'라는 개체가, 서로 독립된 수많은 우주의 무작위 환경에 놓였을 때 어떻게 다르게 성장하고 갈라지는가를 시뮬레이션하고 통계적으로 분석하는 엔진.

**상태: 개발 중 (WIP)** — 현재 데이터 구조와 탄생 판정까지 구현됨.

---

## 개요

핵심 질문: **무한에 가까운 다중 우주에서, 같은 근원을 가진 '나'는 환경과 확률에 따라 어떻게 다르게 살아가는가?**

- 모든 우주의 개체는 **같은 base 성격**에서 출발한다.
- 각 우주는 **독립된 세계**로, 시드(seed)에서 파생된 고유한 환경(탄생 확률·사건 빈도·생존 난이도)을 가진다.
- 개체는 매 시간 단위(tick)마다 확률적으로 발생하는 이벤트로 성격과 상태가 변한다.
- 수많은 우주를 돌려, 개체들이 base에서 **얼마나 / 몇 가지 유형으로 갈라지는지**(divergence)를 분석한다.

개인 사고실험이자 동시성·알고리즘 설계 학습 프로젝트로 진행하며, 완성도가 오르면 분기 시각화 중심의 포트폴리오 데모로 전환하는 것을 목표로 한다.

---

## 핵심 개념

- **개체는 흩어지고, 통계는 수렴한다**: 우주 하나하나의 결과는 제각각이지만, 많이 돌리면 생존율·유형 분포 같은 비율은 안정된 값으로 수렴한다. (몬테카를로)
- **재현성**: 같은 시드는 항상 같은 우주를 만든다. 환경은 시드에서 파생되며, 시드 자체엔 정보가 없다(출발점일 뿐).
- **격리(isolation)**: 우주는 서로의 상태에 접근할 수 없도록 구조적으로 분리된다.

## 실행 방법

Python 3.13 기준. (환경 격리는 conda 권장)

```bash
# 환경 생성 및 활성화
conda create -n multiverse python=3.13
conda activate multiverse

# 의존성 설치 (현재는 numpy만 필요, 분석/시각화 단계에서 추가 예정)
conda install numpy
# 이후: conda install scikit-learn plotly

# 실행
python src/simulator.py
```

> Windows에서 conda는 Anaconda Prompt 또는 PowerShell에서 활성화할 것 (Git Bash에서는 환경이 제대로 물리지 않을 수 있음).

- **1차 프로토타입**: Python + NumPy (연산) / scikit-learn (클러스터링·PCA) / Plotly (시각화)

## 로드맵

1. **데이터 구조 & 우주 하나** — base·State·Universe·탄생 (진행 중)
